# HARI BUSINESS BOT — AI Marketing Partner

**HARI BUSINESS BOT** is a complete, modern, responsive AI-powered SaaS web application designed for small businesses, shops, tuition centres, computer centres, restaurants, salons, freelancers, and local stores in India.

## 🚀 Features

- 📢 **AI Advertisement Generator**: Professional promotional content with headlines, copy, offers, and hashtags.
- 🎨 **Poster Content Generator**: HTML/CSS visual canvas previews with theme switcher (Modern, Premium, Festival, Minimal, Local Business) and PNG image download.
- 📱 **Instagram Generator**: Scroll-stopping hooks, high-converting captions, CTAs, hashtags, and emoji suggestions.
- 💬 **WhatsApp Marketing Generator**: Pre-formatted promotional WhatsApp broadcast messages with 1-click `wa.me` sharing link.
- 🎬 **Reel Script Generator**: 15s, 30s, and 60s video scripts with 5-scene breakdown, visual ideas, and voiceover transcript.
- 📅 **Content Calendar**: Complete 7, 14, or 30-day marketing plan schedule table.
- 🌐 **Tamil + English First-Class Support**: Native Tamil Unicode and hybrid (Tanglish) generation tailored for local business contexts.
- ⚡ **Usage Limit Counter**: Free tier generation counter (5/month) with interactive upgrade modal (Starter ₹199, Business ₹499).
- 🛡️ **Admin Panel (`/admin`)**: Protected metrics view showing user directory, generation analytics, and revenue estimates.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Export**: `html-to-image` for visual poster PNG export

## 🏃 Getting Started

### 1. Clone the repository
```bash
git clone git@github.com:hariharanmct06/Hari-Business-Bot.git
cd Hari-Business-Bot
```

### 2. Install dependencies
```bash
npm install
```

### 3. Setup environment variables
Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```

### 4. Run development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
